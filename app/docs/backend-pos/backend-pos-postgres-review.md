# Backend POS - Review PostgreSQL

Ringkasan penyesuaian untuk PostgreSQL 13+:

## 1) Auto-increment
- Gunakan BIGINT dengan GENERATED BY DEFAULT AS IDENTITY, bukan AUTO_INCREMENT.
- Contoh: id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY.

## 2) Timestamp
- Gunakan timestamptz untuk konsistensi zona waktu.
- created_at, updated_at disarankan bertipe timestamptz.

## 3) JSON
- Gunakan jsonb untuk kolom seperti attrs_json, payload_json.

## 4) Index
- Index komposit pada (tenant_id, outlet_id, created_at) untuk transaksi.
- Index pada (ref_type, ref_id) untuk stock_movements.

## 5) Foreign Key
- ON DELETE RESTRICT untuk transaksi.
- ON DELETE CASCADE hanya untuk tabel pivot (user_roles, role_permissions).

## 6) Naming
- Hindari reserved keywords.
- Gunakan snake_case konsisten.
