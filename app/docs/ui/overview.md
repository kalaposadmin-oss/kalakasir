# UI reference overview

Tujuan dokumen ini: menyelaraskan desain UI baru dengan sistem yang sudah ada tanpa mengubah sistem. Desain dipakai sebagai referensi tampilan, sementara alur dan fitur tetap mengikuti sistem saat ini.

## Sumber desain
- Folder referensi: [app/docs/UI BARU](../UI%20BARU)
- File gabungan lama: [app/docs/UI BARU.txt](../UI%20BARU.txt)

## Tema visual utama
- Font: Inter
- Warna utama: #7BAE9E (sage/teal)
- Latar terang: #F8FAF9
- Latar gelap: #121816

## Prinsip penyelarasan
1. Desain mengikuti sistem, bukan sebaliknya.
2. Nama plan tetap S/M/P sesuai sistem (label UI disesuaikan di tahap implementasi).
3. Aksi dan menu harus mengikuti feature gating yang sudah ada.

## Status ringkas
- Mayoritas layar POS, produk, riwayat, supplier, pembelian cocok dengan modul sistem.
- Beberapa layar butuh penyesuaian karena fitur belum ada atau berbeda nama. Rinciannya ada di screen mapping.

Lihat detail di [app/docs/ui/screen-mapping.md](screen-mapping.md).
